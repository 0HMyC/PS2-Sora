# PS2 Sora v1.0.0
* Edit UV's of Sora's high-poly models for higher quality & accuracy
* Improve accuracy of Sora's gameplay models
* Fix bug that would cause the Dive to the Heart platform that shatters (TODO: name of the disney princess instead!!) to randomly and somehow have it's texture replaced by a UI texture.
* Mod migrated for use with OpenKH Mod Manager directly
  * This has the effect of reducing the download size of the mod a bit, as duplicated assets can just be handled by the mod manager when building a user's mod loadout.
* Remove "Face Only" variant of mod
  * The primary reason this version existed was because previous versions had to rely on texture edits for the high-poly models, which looked pretty rough and blurry *except* for Sora's head, so I made a compromise in having a variant that only changed that since you'd still get the expressiveness benefit. Now that the mod is much more accurate and nicer looking, I don't feel it's worth the effort in trying to maintain a variant that literally only differs in that it changes less.
* Full release
  * This means that all known models that require UV/texture edits have been edited and should be as close to perfectly accurate as possible. It's not impossible that there may be future updates, but the mod is essentially finished now.
